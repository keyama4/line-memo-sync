# ブランド分離の方針（2026-09-22）

「Obsidian Memo」は、発信者タクトの公式 LINE（LIFF 特典アプリ用）とは完全に別のアプリケーションとして見せる。

| 項目 | Obsidian Memo | タクト側 |
|---|---|---|
| LINE 公式アカウント | Obsidian Memo（@450xsede） | 別途作成する配信用アカウント |
| 受付サーバー URL | line-memo-sync.linememo.workers.dev | 使わない（同じ Cloudflare アカウントでも URL にタクトの語を含めない） |
| プラグイン作者表記 | Obsidian Memo | 出さない |
| README・配布物 | タクトへの言及なし | タクトの発信から「こういう道具がある」と紹介する形 |
| 台帳の集計 | Obsidian Memo 運営者として利用 | 発信テーマの参考にする（公表時は匿名の件数のみ） |

このリポジトリと配布物にはタクトの名前・リンクを入れない。要件の経緯（発信戦略）は Vault 側のメモにだけ残す。
